# Gold-loss funnel and floor/tier analysis, Nov 3 jobs

Generated by `docs/analysis/gate_diagnostics/build_funnel_floor.py`; read-only. Zero rule applied: a failed task scores 0 at the answer level. Per-task rows are in `gold_loss_funnel.csv` (one row per dataset, arm, task, file/function) and `floor_tiers.csv` (floor/tier tables are in the sections below).

**Stages** (from `ranked.*` in each results row): *ret50* = `after_retrieval`, the 50 ranked candidates (the ceiling: gold absent here cannot be recovered by anything downstream); *top5* = `retrieved_top5`, the raw chunks the gate sees and the expansion seeds; *expansion* = `after_expansion` (only when graph expansion ran, i.e. GRAPH routes and Always-GRAPH); *pruning* = `after_pruning` and *context* = `final_context` (RAG and GRAPH routes only: on an LC route the answerer is given the long context and these lists do not describe its input, so they are treated as not applicable); *answer* = answer-level Acc@10 (functions) / Acc@5 (files) equal to 1. A task is 'complete' at a stage when every gold item is verbatim in that stage's list. Acc@k is binary per task in this data. Gold files are counted per task as a set (a task with 3 gold files needs all 3).
